Smile Selfie Capture is a fun and interactive Python project that uses computer vision to detect smiles in real time using your webcam and captures a selfie automatically when a smile is detected. It’s built using OpenCV and Haar Cascade classifiers.

🧠 Features
Real-time smile detection via webcam

Automatically saves a selfie when a smile is detected

Uses Haar Cascades for face and smile detection

Lightweight and easy to run

🛠️ Tech Stack
Python

OpenCV

Haar Cascade Classifiers (pre-trained XML models)
